@leizhiren 简单说：模型 id 按各自的 provider 条目解析，所以多供应商同名模型各走各的后端。`codex/gpt-image-*` 走 ChatGPT 账号后端，那个后端忽略请求里的 `model` 字段——ggbdpq 在[上面的评论](https://github.com/yetone/magpie/issues/3513#issuecomment-6461010207)里用真实 Pro 账号验证过，`gpt-image-2`、`gpt-image-2.5` 乃至编造的名字都返回 200 且输出一致，所以那里只列一个 "GPT Image"；`<provider>/gpt-image-*` 走该 provider 自己的条目，OpenAI key 供应商会按请求里的名字处理。所以"怎么工作"看 id 的 provider 部分：互不混淆，语义各自生效。
