gui: an account with no Grok plan says Grok, not an invented SuperGrok (#3668)

The account chip's Grok branch fell back to the literal "SuperGrok" when
no plan was reported, labelling every plan-less account with a tier it
may not be on. The reporter did not capture either account's API
response. A known plan is kept as told; when none is known the pill now
says the provider's own name, Grok, which this function's contract
already is (its vendor and plan): no tier is invented and no new
translation is needed.

Not changed: the community Grok plugin still brands itself
"Grok (SuperGrok)" and does not return a plan, so the real plan title
needs that repo; this change only fixes magpie's own fallback.
