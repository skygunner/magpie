# [bug] 资源库中从 Agent 导入的技能无法真正关闭：实体留在 ~/.agents/skills 时，取消勾选对读共享目录的 Agent 无效

## 环境

- 系统：macOS 26.6.1（Apple Silicon）
- Magpie：0.1.1559
- 资源库目录：`~/.config/magpie/library/skills`
- 共享技能目录：`~/.agents/skills`
- 相关 Agent：dsh、Codex、OpenCode（三者都直接扫描 `~/.agents/skills`）

## 问题

把 Agent 里的技能导入资源库后，**技能实体并没有被收进资源库**，而是原地留在 `~/.agents/skills/<name>`，资源库只在库目录里放了一条指向它的软链接。于是：

- 凡是直接扫描 `~/.agents/skills` 的 Agent（magpie 内共 14 个：codex、gemini、opencode、deveco、crush、dsh、commandcode、devin、droid、cline、grok、grok-app、fx、alma）**始终**能拿到这个技能；
- 资源库里取消勾选，对这些 Agent **没有任何效果**——技能目录里还在，模型照样能调用；
- 界面上只给了一行提示「{agent} 会自行读取此技能所在的 ~/.agents/skills，无论是否勾选都能使用」，但既没说明「为什么关不掉」，也没给「怎么关掉」的入口；
- 更进一步：把技能从资源库「移除」，也只是拿掉库目录里那条软链接，实体仍留在 `~/.agents/skills`，Agent 照样能用，资源库里反而连记录都没了。

结论：用户无法通过资源库收回任何一个 Agent 对某个技能的使用权，勾选框成了「假开关」。

## 复现步骤

1. 技能已安装在共享目录：`~/.agents/skills/drawio-skill/`（真实目录，含 `SKILL.md`）
2. Magpie → 资源库 → 技能 → 发现 → 把 `drawio-skill` 导入资源库
3. 查看实体位置，实体没有搬进库目录：

```console
$ ls -la ~/.config/magpie/library/skills/
lrwxr-xr-x  1 janda  staff  40 Oct 10 18:55 drawio-skill -> /Users/janda/.agents/skills/drawio-skill
```

4. 在资源库里把 `drawio-skill` 的所有 Agent 勾选都取消（dsh / Codex / OpenCode …）：

```console
$ jq '.skills' ~/.config/magpie/library.json
[
  {
    "name": "drawio-skill",
    "source": { "kind": "folder", "dir": "/Users/janda/.agents/skills/drawio-skill" },
    "agents": []            # ← 已全部取消
  }
]
```

5. 共享目录纹丝不动：

```console
$ ls -ld ~/.agents/skills/drawio-skill
drwxr-xr-x  7 janda  staff  224 Jul 27 15:32 /Users/janda/.agents/skills/drawio-skill
```

6. 新开一个 dsh 会话 → 技能目录里 `drawio-skill` 依然在列，模型可以直接调用（本次会话即复现：会话的可用技能清单中仍包含 `drawio-skill`）。
